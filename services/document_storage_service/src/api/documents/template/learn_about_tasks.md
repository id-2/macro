Задачи — это, по сути, *особые* документы. В них есть всё, что в обычном документе, и ещё:

- **Задачи можно *назначать*.** Если назначить задачу человеку, уведомление появится в его входящих.
- __У задач есть *статус* и *приоритет.*__ Они видны в метках под названием и везде, где задача упомянута.
- **Задачи живут в *виде задач*.** Откройте вид задач сочетанием `g -> t`, чтобы увидеть все свои задачи.

Создайте задачу сочетанием `c -> t` или командой `/task`.

Если нужны дополнительные свойства, например *сторипоинты*, добавьте их как своё свойство в панели сведений.
